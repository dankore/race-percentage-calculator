How the DNA Import Hub Works

  1. 1. Drop any supported file or paste the raw text. We automatically detect vendors, normalize percentage totals, and surface the most relevant regions.
  2. 2. Compare the kit to your current calculator results. You'll see a match score, average difference, and a region-by-region delta table.
  3. 3. Click “Send to Calculator” for Mother or Father. We'll transfer the structured data to the main race calculator and pre-fill the entries automatically.

Heads up:

After sending data to the calculator, this page will redirect you to the main tool. If it doesn't, open race-calculator.dankoresoft.com and your latest import will still be waiting for you for up to 10 minutes.
